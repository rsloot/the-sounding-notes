# The Sounding: data notes

Full sourcing for each article in [The Sounding](https://thesounding.substack.com), Ryan Sloot's economics newsletter.

The rules:

- Every number comes from a primary source, named here with its series ID, the date it was pulled, and its sampling frequency.
- Anything I computed is labeled "my arithmetic", so you can check it.
- Prior work is credited, and press or web figures I could not reproduce are labeled as such.
- Every forecast is dated and says what would prove it wrong.
- Corrections after publication are logged in each article's notes with a date, and the change history is public in this repository.
